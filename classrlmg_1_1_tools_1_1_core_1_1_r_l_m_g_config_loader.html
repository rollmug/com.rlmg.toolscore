Detailed Description

Configures the logger, attract and app manager components in RLMG Core.

Will Instantiate a RLMGLogger instance if not already present.

◆ OnLocalSuccess()

override IEnumerator rlmg.Tools.Core.RLMGConfigLoader.OnLocalSuccess ( UnityWebRequest  webRequest)
protected

Parses the config and, with good data, sets up our most frequently used components.

If it's blank or fails to parse, logs an error and the load reports Failed (and AnyLoadFailed fires) - logged rather than thrown, so loading still finishes. The file itself is left as-is.

◆ PopulateConfigData()

Sets every RLMGConfigData field from the current settings of the components this configures.

Values with no live source (e.g. no AppManager instance, or the attract path, which isn't stored after it's loaded) are taken from the last loaded Data, if any.
